# QuickSurveys

        This Flutter Project is known as the QuickSurvey App.  
    An application that allows users via a created account either by logging in an already established 
    account or register a new account via the login page when first opening the app through either a google or email login.
    Form there, users will enter to the main dashboard where their find two tabs, one "My Surveys" tab for the user account.
    Here, they can find a panel that shows all their created surveys they published with a option manu subpanel button.
    It's here, you'll find the ability to edit created surveys, view responses from users, and delete them;
    with a button on the bottom to create surveys. 
       
     Clicking or taping on either the edit survey option or create survey button, you open survey builder page.
    Here, users can enter up to 10 questions with five question types of short answer, paragraph, multiple choice, liner scale, checkboxes along with the option to make them a requiement to answer.
    With the ability to costumize the questions, options, and liner scale amount and options should that option be chosen and reorder the questions with a click and drag function.
    Along with the toggles options to allow anoumyous users to take the survey or require the users taking the survey to enter their name and/or email then either selecting "save draft" to save the survey as a draft, or "publish" to publish the survey.
    The published surveys would show up in the dashboardand a popup menu will show the user a copiable link to view the survey(Currently a work in progress for the Beta).
    
        As for takeing surveys via your account; it can be done by tapping or clicking on the Explore Surveys tab in the dashboard.
    Here, users can find a survey by it's name or by user's name with a serach function.
    From there you can seletc from the option panel the "Open Survey" to take the survey, and publish you results.
    To view the results, you click on th option panel in the "My Surveys" Tab and click on the "Analyze Responses" option for the survey you opened the option panel for.
    From there you cand view the overview tab for all the questions and answers chosen with the question type that have multiple options in a bar graph form. 
    Meanwhile the Individual Response tab shows the individual responses of attempts, which shows rather the attempt was anomayous user or if the attempt shows the name and email of the user along with their answers for each question.
    All surveys, responses, and users being stored within an Firebase database and the app being avalible on Android, IOS, and Web Browser format.
